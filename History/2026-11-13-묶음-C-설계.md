# 묶음 C 설계: 밤 재분배, 순공시간과 공부 잔디

- 날짜: 2026-11-13
- 단계: 묶음 B 다음 설계(구현은 채팅 연결 단계와 아침 알림 단계)
- 관련: [설계](../docs/superpowers/specs/2026-11-13-study-time-heatmap-design.md), [묶음 B 기록](2026-11-10-공부-데이터-채우기.md)

## 요청

묶음 B를 마친 뒤 사용자가 두 가지를 물었다.

- 계획 재분배는 하루가 지날 때마다 스케줄러로 하면 좋겠다. 체크하거나 채팅으로 "~했음"을 보낼 때마다 재분배되어 분량이 바뀌면 힘들 것 같다. 공부 설정 변경은 바로 재분배해야 한다.
- 오늘 분량에 예상 소요 시간을 보여 줄 수 있나. 채팅으로 "나 오늘 순공 N시간 N분이야"를 보내 정확도를 높이고 싶다.

## 한 일

- 지금 동작을 먼저 설명했다. 체크·해제는 원래 재분배하지 않고, 앱을 열 때 이월만 하루 한 번 돈다. 채팅 보고 뒤 재분배는 아직 만들지 않은 요구사항 C 문서에만 있다.
- 스케줄러가 필요한 진짜 이유를 짚었다. 아침 알림은 서버가 보내므로, 앱을 열기 전이면 재분배 전 분량을 알리게 된다.
- 설계 문서 [2026-11-13-study-time-heatmap-design.md](../docs/superpowers/specs/2026-11-13-study-time-heatmap-design.md)를 썼다. C1(밤 재분배)은 결정만 적고 구현은 아침 알림 단계로 미뤘다. C2(순공시간과 공부 잔디)는 저장(`study_time` 테이블, DB 함수 `record_study_time`), 채팅 보고 규칙, 잔디 칸 규칙, 연속 공부 기준을 정했다.
- 채팅 연결 계획 요구사항 C를 "채팅 보고는 진도만 바꾸고 재분배는 밤에"로 고치고, 순공시간 보고 의도를 더했다. SERVICE_FLOW 6장(재분배 시점)과 "구현 전 결정할 것"의 이월 방식, 로드맵, CLAUDE.md의 `plan-generator` 설명도 맞췄다.

## 고려한 상황과 해결

### 1. 예상 소요 시간

- 상황: 처음에는 교재별 단위당 시간을 두고 순공시간으로 보정하는 안을 냈다. 처음 값을 사용자가 넣지 않도록 LLM 추정·규칙표·처음엔 표시 안 함 세 가지를 비교했다.
- 해결: 사용자가 예상 소요 시간 자체를 빼기로 했다. "오늘 4시간밖에 못 하는데 분량이 예상 6시간이면 숨이 턱턱 막힐 것 같다." 숫자로 재촉하지 않는 coach-tone과도 맞는다. 교재별 시간 값도 필요 없어졌다.

### 2. 순공시간 저장 위치

- 선택지: `study_logs`에 칸 더하기, 새 테이블.
- 해결: 새 테이블 `study_time`(사용자·날짜마다 한 줄). `study_logs`는 교재 범위를 적는 줄이라 하루 합계와 성격이 다르다. 더하기("1시간 더 했어")가 겹쳐도 맞도록 DB 함수 한 문장(`insert … on conflict … do update`)으로 저장한다.

### 3. 순공시간을 안 보낸 날의 잔디

- 선택지와 사용자 반응:
  - 보고 없는 날은 체크 기록이 있으면 가장 옅은 칸 → 사용자는 분량 진행률로 정하자고 했다.
  - 다른 색 계열 → 회갈색은 티가 안 난다, 연두~녹색은 어떤가 → 녹색을 다른 화면(분량 완료 표시)에도 쓸지 물었다 → 튈 것 같아 녹색은 쓰지 않기로 했다.
  - 칸을 채우지 않고 점만 찍기 → 채택. 점 진하기를 진행률로 나눌지 물었고, 한 가지 색(B)으로 정했다.
- 해결: 순공시간이 있으면 칸을 주황으로 채우고, 없고 진행한 분량이나 공부 기록이 있으면 빈칸에 주황 점 하나. 새 색 토큰은 만들지 않는다. 적록 색약 등을 위해 칸마다 날짜와 내용을 `title`·`aria-label`로 단다.

### 4. 새벽에 보낸 "오늘 순공"

- 상황: 밤늦게 공부를 마치고 자정 넘어 보내면 "오늘"이 이미 다음 날이다.
- 해결: 사용자 시간대로 새벽 0~4시의 "오늘"은 전날로 본다. 사용자가 설계 확인 때 받아들였다.

## 남은 일

- (사용자) 설계 문서 검토
- 구현 계획: C2는 채팅 연결 Task 3~7과 함께 쓴다(테이블·잔디를 먼저 할지 계획에서 정함). C1은 아침 알림 단계 계획에서 쓴다.
