# 시험일 달력 교체와 계획 재분배 CORS 오류

- 날짜: 2026-11-09
- 단계: 1단계 Task 2 Step 8(시험일 저장·D-day) 확인 중 나온 문제와 화면 개선
- 관련: [DESIGN.md](../DESIGN.md) "날짜 선택", "라이브러리·도구", [1단계 채팅 연결 진행](2026-10-30-채팅-연결.md)

## 요청

1. 공부 설정의 시험일 입력(브라우저 기본 날짜 입력)이 보기 좋지 않으니, react-calendar로 구글 캘린더 느낌의 달력을 만들어 달라고 했다.
2. 시험일을 저장하면 "시험일은 저장했지만 계획을 다시 나누지 못했어요. (Failed to send a request to the Edge Function)"가 뜨고, 콘솔에 `plan-generator` preflight가 CORS로 막혔다는 오류가 났다. 원인을 설명하고, 해결책을 제시한 뒤 고쳐 달라고 했다.

## 한 일

1. CORS 오류 조사
   - 브라우저와 같은 OPTIONS 요청을 curl로 보냈다. `404`, `sb-error-code: NOT_FOUND`가 왔다. 개발 프로젝트에 `plan-generator` 함수가 배포되지 않은 상태였다.
   - 함수 코드의 `withSupabase`(`@supabase/server` 1.9.2)는 기본으로 CORS preflight를 처리한다(README `cors: 'default'`). 코드는 고칠 것이 없었다.
2. ☁️ 사용자 승인 뒤 `plan-generator`만 개발 프로젝트에 배포했다. PowerShell에서 `npx supabase functions deploy plan-generator --project-ref ishtebcswgyagbbaakpx --use-api`로 했다. `chat`, `daily-briefing`은 아직 템플릿이라 배포하지 않았다.
   - 확인: 같은 OPTIONS 요청에 `204`와 `Access-Control-Allow-Origin: *`, `content-type`이 들어간 허용 헤더가 왔다. 인증 없는 POST는 `401 MISSING_CREDENTIALS`로, 의도한 동작이다.
   - 로그인한 상태에서 시험일을 저장해 계획이 나뉘는지는 사용자가 브라우저로 확인한다.
3. 달력 교체
   - `react-calendar@6.0.1`을 설치했다.
   - `components/ui/DatePicker.tsx`를 새로 만들었다. 입력 칸을 누르면 아래에 달력이 열린다.
     - 머리줄은 직접 만들었다. 왼쪽에 `2027년 2월`, 오른쪽에 이전·다음 화살표가 있다.
     - 일요일부터 시작하고 6주를 고정으로 보인다. 날짜 칸은 원이다.
     - 고른 날은 `bg-accent`, 오늘은 `text-accent`로 보인다. 날짜를 고르면 닫힌다. 바깥을 누르거나 Esc를 눌러도 닫힌다.
     - "날짜 지우기"를 넣었다.
   - `ExamDateForm`의 `<input type="date">`를 `DatePicker`로 바꿨다. 시험일은 내일부터 고를 수 있다.
   - `libs/date.ts`에 `formatFullDate`, `keyToLocalDate`, `localDateToKey`를 추가했다.
   - DESIGN.md를 고쳤다. 공부 설정 와이어프레임, 컴포넌트 메모 "날짜 선택", 라이브러리·도구에 react-calendar 사용 규칙을 넣었다.
   - 확인: `format`, `build`, `lint` 오류 0. 빌드 CSS에 요일 줄용 `abbr[title]` 규칙이 생긴 것을 확인했다. 화면 확인은 로그인이 필요해서 사용자가 한다.

## 고려한 상황과 해결

### 1. CORS 오류인데 원인은 함수 없음

- 상황: 브라우저는 "preflight가 HTTP ok가 아니다"라고만 보여 준다. CORS 설정 문제처럼 보이지만, 실제 응답은 404였다.
- 해결: 코드를 고치기 전에 OPTIONS 요청을 직접 보내 상태 코드와 `sb-error-code`를 확인했다. 그래서 배포만으로 해결했다.
- 남긴 규칙·프로세스: Edge Function CORS 오류가 나면 먼저 OPTIONS 응답의 상태 코드를 확인한다. 404면 배포 누락이다.

### 2. react-calendar를 Tailwind 규칙 안에서 꾸미기

- 상황: react-calendar는 자기 CSS 파일과 `.react-calendar__*` 클래스로 꾸미게 되어 있다. 이 프로젝트는 유틸리티 클래스만 쓰고 `index.css`에 커스텀 클래스를 두지 않는다.
- 선택지:
  - (1) 라이브러리 CSS를 불러와 덮어쓰기
  - (2) `index.css`에 `.react-calendar__*` 규칙 추가
  - (3) 라이브러리 CSS 없이 `tileClassName`, 직접 만든 머리줄, 감싸는 요소의 변형 클래스로만 꾸미기
- 해결: (3)을 골랐다. 날짜 칸 배치는 라이브러리의 인라인 flex 스타일이 잡아 줘서 CSS가 없어도 된다. 요일 줄은 `<abbr title>`, 날짜 칸은 title 없는 `<abbr>`로 그려지므로 `[&_abbr[title]]:`로 요일 줄만 꾸몄다. 한국어 로케일은 날짜를 `27일`로 표시해서 `formatDay`로 숫자만 보이게 했다.

### 3. 달력이 좁은 휴대폰 화면 밖으로 나감

- 상황: 달력은 입력 칸 왼쪽 아래에 붙어 열린다. 입력 칸 앞에 "시험일" 라벨이 있어서, 360px 화면에서 288px 달력이 오른쪽으로 넘친다.
- 해결: 달력 폭을 `min(18rem, 100vw - 6rem)`으로 두었다. 날짜 칸은 `aspect-square`라 폭이 줄어도 원 모양이 유지된다.
