# 국어 공부법 (초안)

> ✏️ 사용자 수정 예정. 실제 시험 경험·추천 방식으로 고친다.

## 과목 특징

- 문법·어휘(맞춤법, 표준어, 외래어·로마자 표기 등), 독해(비문학·문학), 논리·추론 문제로 구성된다.
- 독해·추론은 시간 싸움이고, 문법·어휘는 암기량 싸움이다.
- ✏️ 최근 출제 기조(문법 비중, 독해·추론 비중 변화)는 인사혁신처 공지로 확인 후 적는다.

## 단계별 공부법

| 단계 | 공부법 |
|---|---|
| 기본 | 문법 개념을 기본서로 1회독. 독해는 하루 지문 2~3개로 감 유지 |
| 기출 | 문법·어휘 기출 반복, 헷갈리는 규정은 정리 노트로 |
| 실전 | 하프·봉투 모의고사로 시간 배분 연습. 독해 지문당 시간 재기 |
| 마무리 | 정리 노트와 오답 위주. 새 문법 범위는 늘리지 않음 |

## 고민별 처방

| 고민 | 처방 |
|---|---|
| 맞춤법·표준어가 계속 헷갈림 | 틀린 단어만 모아 카드로 만들고 매일 5분 반복 |
| 독해 시간이 부족함 | 문단별 핵심어 표시 → 선지 먼저 보기 연습. 지문당 목표 시간 정하기 |
| 문학이 감으로만 풀림 | 기출 문학 지문에서 "근거 문장"을 찾아 표시하는 연습 |
| 모의고사 점수가 들쭉날쭉 | 틀린 문제를 유형(문법/독해/문학/추론)으로 나눠 약한 유형부터 |
| ✏️ (추가) | |
