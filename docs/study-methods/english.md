# 영어 공부법 (초안)

> ✏️ 사용자 수정 예정. 실제 시험 경험·추천 방식으로 고친다.

## 과목 특징

- 어휘, 문법, 독해(주제·요지, 빈칸, 순서·삽입 등), 생활영어로 구성된다.
- 어휘는 모든 영역의 바탕이고, 독해는 속도와 정확도가 함께 필요하다.
- ✏️ 최근 출제 기조(어휘·문법 비중, 독해 유형 변화)는 인사혁신처 공지로 확인 후 적는다.

## 단계별 공부법

| 단계 | 공부법 |
|---|---|
| 기본 | 단어장 1회독 시작(매일 일정량), 문법 기본 개념 정리, 독해는 구문 분석 위주 |
| 기출 | 기출 어휘·문법 반복, 독해 유형별 풀이법 익히기 |
| 실전 | 하프모의고사를 매일 1회, 시간 재고 풀기. 모르는 단어는 단어장에 추가 |
| 마무리 | 누적 단어장·오답 위주 반복, 생활영어 표현 정리 |

## 고민별 처방

| 고민 | 처방 |
|---|---|
| 단어가 금방 잊힘 | 하루 50개씩 나눠 외우고 다음 날 아침·주말에 다시 보기(간격 반복) |
| 독해가 느림 | 문장 구조 끊어 읽기 연습 → 익숙해지면 시간 재고 풀기 |
| 빈칸·순서 문제를 자주 틀림 | 정답 근거 문장을 찾아 표시하고, 틀린 이유를 한 줄로 기록 |
| 점수가 오르지 않음 | 틀린 문제를 어휘/문법/독해로 나눠 가장 많이 틀리는 영역부터 |
| ✏️ (추가) | |
