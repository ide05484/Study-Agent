# 영어

## 과목 특징
- 2025·2026년 국가직은 두 해 모두 어휘 3, 문법 3, 생활영어 2, 독해 12문항이었어요. ==독해가 점수를 가르고, 시간 압박이 가장 큰 과목==이에요.
- 어휘는 밑줄 동의어 고르기에서 문장 문맥에 맞는 단어 고르기로 바뀌었어요. 다만 독해 지문이 길어 독해용 어휘량은 줄지 않았다고 보는 편이 안전해요.
- 문법은 빈칸형 1문항, 밑줄 중 틀린 것 고르기 2문항이었어요. 병치처럼 문장 구조를 분석해야 하는 문항이 나와요.
- 독해 오답은 빈칸·삽입·순서·삭제 네 유형에 몰려요. 공지문·이메일·안내문 같은 실용문도 나와요.
- 합격생 설문에서 영어는 부담 과목 2위였지만, 30% 정도는 3개월 안에 점수가 올랐다고 답했어요.

## 단계별 공부법
| 단계 | 공부법 |
|---|---|
| 기본 | 단어를 매일 정해진 양만큼 외우고, 문법 개념을 실제 문장에 적용해 봐요. 기초가 부족하면 기초 어휘 → 기초 문법 → 구문 독해 순서로 문장을 해석할 수 있는 상태부터 만들어요 |
| 기출 | 2025·2026년 기출과 예시문제를 시간 재고 풀어요. 2024년 이전 기출은 어휘·문법 기본기 점검용으로만 써요 |
| 실전 | 하프 모의고사를 15분 제한으로 풀고, 25문항 기준으로 시간을 줄이는 연습을 해요 |
| 마무리 | 누적 단어장과 오답 위주로 봐요. 단어 암기는 시험 직전까지 끊지 않아요 |

## 고민별 처방
| 고민 | 처방 |
|---|---|
| 단어가 금방 잊힘 | **하루 50개 안팎을 매일** 외우고, 이동 시간에 다시 봐요. 하루 양을 늘리기보다 끊기지 않게 해요 |
| 빈칸 문제를 자주 틀림 | 빈칸 위치와 그 문장의 구조를 먼저 확인하고, 근거 문장에 표시해요 |
| 삽입·순서 문제를 자주 틀림 | 연결어·접속사·대명사를 단서로 앞뒤 문장을 이어 봐요 |
| 무관한 문장 찾기를 틀림 | 문장 사이 흐름이 아니라 글의 주제에서 벗어났는지로 판단해요 |
| 독해 시간이 부족함 | 실전과 같은 시간 안에 풀어요. 실용문은 제목과 날짜·장소·대상 같은 정보 항목을 먼저 훑는 방법이 도움이 되는 편이에요 |
| 점수가 오르지 않음 | 오답을 어휘 부족·구조 파악 실패·시간 부족으로 나누고, 가장 많은 원인부터 고쳐요. 매일 모든 과목은 계획대로 하고 영어에 추가 시간을 써요 |
| 생활영어에서 실수함 | 빈출 표현을 익히되, 대화 흐름상 들어갈 말을 고르는 연습에 무게를 둬요 |

## 하루 공부 예시
- 단어 50개 안팎(이동 시간 반복 포함)
- 하프 모의고사 1회, 15분 제한
- 틀린 문제와 모르는 단어 정리
