# 공중보건 공부법 (초안)

> ✏️ 사용자 수정 예정. 실제 시험 경험·추천 방식으로 고친다.

## 과목 특징

- 범위가 넓고 암기 비중이 크다. 공중보건 총론, 역학, 감염병 관리, 보건통계, 환경보건, 산업보건, 식품위생, 보건영양, 모자·인구·학교·노인·정신보건, 보건교육 등을 다룬다.
- 역학·보건통계는 개념 이해와 계산(비율, 지표 등)이 필요하다.
- 감염병 분류, 통계 수치처럼 법령·자료 개정에 따라 바뀌는 내용이 있다.
- ✏️ 단원별 출제 비중, 최근 개정 사항은 확인 후 적는다.

## 단계별 공부법

| 단계 | 공부법 |
|---|---|
| 기본 | 기본서로 전체 단원 구조 파악, 1회독은 빠르게. 역학·통계 개념은 이해 위주 |
| 기출 | 단원별 기출 반복, 자주 나오는 표·분류는 직접 써 보며 정리 |
| 실전 | 모의고사로 전 범위 점검, 약한 단원 재회독 |
| 마무리 | 요약 노트·암기 카드 반복, 최근 개정 내용 확인 |

## 고민별 처방

| 고민 | 처방 |
|---|---|
| 외울 게 너무 많음 | 기출에 자주 나온 표·분류부터 우선순위를 정해 외우기. 나머지는 회독으로 익숙하게 |
| 외워도 금방 잊힘 | 백지에 단원 목차와 핵심어 떠올려 쓰기(인출 연습), 간격 두고 반복 |
| 역학·통계 계산이 어려움 | 공식 하나당 기출 예제 2~3개를 직접 풀어 보기 |
| 비슷한 개념이 헷갈림 | 헷갈리는 개념끼리 비교표 만들기 |
| ✏️ (추가) | |
