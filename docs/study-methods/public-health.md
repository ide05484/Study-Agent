# 공중보건

## 과목 특징
- 같은 주제가 해마다 되풀이돼요. 식품 보존법, 국민건강증진종합계획, 먹는물 수질 기준, 오존이 여러 해 반복해 나왔어요. ==반복 출제 주제는 무실점==이 목표예요.
- **역학은 매년 출제**돼요. 연구 설계(단면·코호트·환자-대조군), 발생률·유병률, 민감도, 감염재생산수 같은 개념이 나왔어요.
- 검역법, 진료기록 보존기간, 암검진, 금연구역처럼 법령 세부 조항까지 문항이 돼요.
- 개정 사항이 직접 문항이 돼요. 2026년 3월 제6차 국민건강증진종합계획(2026~2030)이 발표됐고, 니파바이러스감염증은 제1급 감염병으로 지정됐다고 보도됐어요.
- 건강보험·법규·보건사업 기획처럼 보건행정과 겹치는 문항이 가장 큰 묶음으로 보여요. 두 과목을 함께 공부하면 효율적이에요.

## 단계별 공부법
| 단계 | 공부법 |
|---|---|
| 기본 | 강의나 기본서로 전체 단원을 한 번 돌리고, 같은 주에 그 단원 기출을 함께 풀어요 |
| 기출 | 기출을 반복하되, 점수가 멈추면 기본서로 돌아가 정의·수치를 다시 봐요. 기출을 볼 때는 "내가 무엇을 놓치고 있나"를 기준으로 삼아요 |
| 실전 | 모의고사로 구멍 난 단원을 찾고, 그 단원만 기본서로 다시 회독해요 |
| 마무리 | 시험 2~3개월 전부터 법령 개정 이력, 감염병 분류표, 국민건강증진종합계획 원문을 교재와 대조해요. 마지막 2주는 전공 최종 정리에 써요 |

## 고민별 처방
| 고민 | 처방 |
|---|---|
| 기출은 맞는데 시험에서 틀림 | 기출만 훑으면 "안다는 착각"이 생겨요. ==기본서로 돌아가 정의·수치를 손으로 쓰며 정밀하게 외워요== |
| 외울 게 너무 많음 | 반복 출제 주제부터 확실히 해요. 감염병 급별 목록, 매개체·병원체, 식중독 원인균, 환경 기준 수치, 법정 기간은 표로 만들어요 |
| 외워도 금방 잊힘 | 표를 덮고 백지에 다시 써 보며 확인해요(백지 복기). 간격을 두고 반복해요 |
| 감염병이 헷갈림 | 급별 종수보다 특정 질환의 급수, 신고 시기, 최근 새로 들어간 질환이 함정이 되기 쉬워요 |
| 역학·통계 계산이 어려움 | 치명률, 민감도·특이도, 상대위험도·교차비 같은 공식을 분자·분모까지 한 장에 정리하고 기출 계산 문항을 반복해요. 계산 문제는 해마다 0~2문항 정도로 보여요 |
| 보건행정과 겹치는 부분이 헷갈림 | 사회보장·건강보험, 보건법규, 보건사업 기획·평가 모형은 한쪽 교재에 모아 두 과목 회독 때마다 함께 봐요 |
| 기본서와 기출 중 무엇을 반복할지 모르겠음 | 기출 → 기본서 왕복이 기본이에요. 기출 밖에서도 나온다고 보고 기본서를 3~4회독한 합격자 사례도 있으니 내게 맞는 쪽을 골라요 |
