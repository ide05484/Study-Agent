# 보건행정

## 과목 특징
- 반복 출제 주제가 뚜렷해요. 예산(준예산, 예산 원칙, 추경), 인사평정 오류, 도나베디안 질 평가, BPRS, 의료기관 인증이 여러 해 나왔어요.
- 행정이론(조직·인사·재무·기획과 정책)이 해마다 7~11문항 정도로 가장 큰 덩어리로 보여요. 법규·보건조직은 3문항 안팎으로 일정한 편이에요.
- ==변별은 법령 세부 요건에서 나와요.== 요양병원 입원 대상, 신의료기술평가 대상, 전문병원 지정 요건처럼 시행규칙 수준까지 출제됐어요.
- 건강보험·의료보장 세부(본인부담상한제, DRG, 재가급여 본인부담, 현금급여)와 학자·모형 이름을 연결하는 문항이 해마다 있어요.
- 공중보건과 겹치는 범위가 커서 두 과목을 함께 공부하면 효율적이에요.

## 단계별 공부법
| 단계 | 공부법 |
|---|---|
| 기본 | 이론 강의나 기본서로 단원 흐름을 잡아요. 행정학 기본서를 따로 볼 필요는 낮은 편이고, 보건행정 기본서의 해당 단원과 기출로 충분해 보여요 |
| 기출 | 기출을 풀며 이론 노트를 복습하고, 구멍이 드러난 단원은 기본서를 정독한 뒤 다시 기출로 돌아가요 |
| 실전 | 모의고사를 실제 OMR로 치러요. 합격자 사례에서 가장 도움이 됐다고 꼽은 방법이에요 |
| 마무리 | 반복해서 틀리는 내용만 모은 노트를 외워요. 본인부담률처럼 해마다 바뀌는 수치는 시험 직전에 법령과 고시로 확인해요 |

## 고민별 처방
| 고민 | 처방 |
|---|---|
| 이론이 다 비슷해 보임 | ==비교표로 정리해요.== NHI와 NHS, 지불제도별 장단점, 계급제와 직위분류제, 엽관주의와 실적주의, 예산 원칙과 종류, 평정 오류 유형이 좋은 주제예요 |
| 학자·모형 이름이 안 외워짐 | 학자 이름과 모형을 한 줄씩 짝지어 카드로 만들고, 덮고 떠올리며 확인해요 |
| 제도가 잘 안 외워짐 | 건강보험·의료급여·장기요양을 보험자·가입자·급여·재원 같은 틀로 먼저 그림을 그리고, 그 위에 수치를 얹어요 |
| 법규 문항을 자주 틀림 | **법규는 따로 공부해요.** 의료법과 지역보건법은 조문을 직접 확인해요 |
| 공중보건과 겹치는 부분이 헷갈림 | 겹치는 단원은 한쪽 교재에 모아 두 과목 회독 때마다 함께 보고, 두 과목 기출을 번갈아 풀어요 |
| 지엽 문항에 시간을 많이 씀 | 반복 주제를 먼저 모두 확보하고, 연금·노인복지·산업보건 같은 주변 법제의 지엽 문항은 뒤로 미뤄요 |
| 비전공이라 예산·인사·정책이 낯섦 | 전공 배경에 따라 약한 곳이 달라요. 낯선 단원에 추가 시간을 쓰되, 매일 모든 과목은 계획대로 해요 |
