# 보건행정 공부법 (초안)

> ✏️ 사용자 수정 예정. 실제 시험 경험·추천 방식으로 고친다.

## 과목 특징

- 보건행정 총론, 보건의료체계, 보건정책, 기획, 조직, 인사, 재무(예산), 의료보장·사회보장(건강보험 등), 보건의료 관련 법·제도 등을 다룬다.
- 행정학 이론(조직·인사·재무)과 보건의료 제도가 섞여 있어, 이론은 이해·비교, 제도는 암기가 필요하다.
- 제도·법령은 개정에 따라 바뀌므로 최신 내용 확인이 중요하다.
- ✏️ 단원별 출제 비중, 최근 제도 개정 사항은 확인 후 적는다.

## 단계별 공부법

| 단계 | 공부법 |
|---|---|
| 기본 | 기본서로 단원 흐름 파악. 행정학 이론은 학자·모형 이름보다 핵심 개념 먼저 |
| 기출 | 단원별 기출 반복, 이론·제도별로 자주 나오는 비교 포인트 정리 |
| 실전 | 모의고사로 전 범위 점검, 제도 관련 최신 개정 확인 |
| 마무리 | 비교표·요약 노트 반복, 숫자·연도·기관명 등 세부 암기 점검 |

## 고민별 처방

| 고민 | 처방 |
|---|---|
| 이론이 다 비슷해 보임 | 비슷한 이론·모형끼리 비교표(특징, 장단점, 대표 학자) 만들기 |
| 제도가 잘 안 외워짐 | 제도를 "누가 / 대상 / 재원 / 방식"처럼 같은 틀로 정리 |
| 공중보건과 겹치는 부분이 헷갈림 | 겹치는 단원은 한 노트에 같이 정리해서 한 번에 회독 |
| 기출은 맞는데 모의고사에서 틀림 | 틀린 선지의 근거를 기본서에서 찾아 표시, 지엽 내용은 표시만 하고 넘어가기 |
| ✏️ (추가) | |
