# 보건직 과목별 공부법

이 앱의 코치가 과목별 공부법을 제안할 때 따르는 기준이다. 이 폴더가 **앱 공부법 내용의 원본**이다. 앱(Edge Function 프롬프트, 공부 설정 화면의 "기본 공부법")에 넣을 때는 여기서 옮기고, 내용이 바뀌면 함께 맞춘다.

## 과목

| 과목 | DB 값 | 참고 파일 |
|---|---|---|
| 국어 | `korean` | [korean.md](korean.md) |
| 영어 | `english` | [english.md](english.md) |
| 공중보건 | `public_health` | [public-health.md](public-health.md) |
| 보건행정 | `health_admin` | [health-admin.md](health-admin.md) |

해당 과목 파일만 읽는다. 여러 과목의 균형(시간 배분)을 다룰 때만 여러 파일을 본다.

## 공부법을 제안하는 순서

1. **과목과 문제를 특정한다.** 어떤 과목인지, 어떤 어려움인지(암기, 이해, 독해 속도, 시간 부족, 실수, 성적 정체) 확인한다. 모호하면 묻는다. 막연한 "열심히 하세요"보다 문제에 맞는 처방 하나가 훨씬 도움이 된다.
2. **데이터로 근거를 찾는다.** `mock_exam_scores`(과목별 점수 추이), `study_logs`(최근 공부량·틀린 문제 수), `books`·`daily_tasks`(진도·밀린 분량)를 본다.
3. **학습 단계를 판단한다.** 남은 기간과 진도로 지금이 어느 단계인지 본다. 단계마다 맞는 공부법이 다르다.
4. **처방은 1~2개만, 바로 할 수 있게.** 과목 파일의 "고민별 처방"에서 고르고, 오늘 분량과 연결한다.
5. **말투는 [코치 톤](../coach/coach-tone.md)을 따른다.** 공감 → 근거 있는 칭찬 → 처방 → 다음 행동 질문.

## 학습 단계 (공통)

| 단계 | 시기 (기준) | 중심 활동 |
|---|---|---|
| 기본 | 시험 6개월 이상 전 | 기본서·강의로 전체 구조 이해, 1회독 |
| 기출 | 시험 6~3개월 전 | 기출 반복, 자주 나오는 개념 정리, 회독 늘리기 |
| 실전 | 시험 3~1개월 전 | 모의고사·하프모의고사, 시간 관리, 오답 정리 |
| 마무리 | 시험 1개월 이내 | 오답노트·요약 위주 반복, 새 교재는 늘리지 않음 |

시기는 기준일 뿐이다. 진도가 늦으면 단계를 당기지 말고 남은 기간에 맞춰 회독 범위를 줄이도록 제안한다.

## 공통 원칙

- **회독**: 처음부터 완벽하게 외우려 하지 말고 여러 번 빠르게 돌린다. 회독할수록 속도가 붙는다.
- **기출 우선**: 무엇이 자주 나오는지 기출로 확인하고, 그 범위를 먼저 확실히 한다.
- **오답 관리**: 틀린 문제는 이유(몰라서/헷갈려서/실수)를 나눠 기록하고 다시 푼다.
- **매일 조금씩 모든 과목**: 한 과목에 몰리면 다른 과목 감각이 떨어진다. 이 앱의 계획(`plan-generator`)도 매일 모든 교재를 나눠 배정한다.

## 주의

- 과목 파일 중 "초안"으로 표시된 내용은 일반적인 수험 공부법이다. 출제 비중, 출제 기조 변경, 법령 개정처럼 **확인되지 않은 시험 정보는 사실처럼 단정하지 않는다.**
- 특정 강사·교재·학원을 추천하지 않는다. 사용자가 이미 쓰는 교재(`books`)를 기준으로 제안한다.
- 건강을 해치는 공부량(밤샘, 수면 줄이기)은 권하지 않는다.
