# 국어

## 과목 특징
- 2025년부터 암기형에서 이해·추론형으로 바뀌었어요. 2025년 지방직은 20문항 중 확인추론·응용추론·논리비판이 15문항이었고 문학은 나오지 않았어요.
- ==지식을 쌓는 과목이 아니라 정해진 시간 안에 읽고 판단하는 기술 과목==으로 다루는 편이 출제 기조와 맞아요.
- 암기형 문법 규정 대신 공문서 고쳐쓰기로 어휘·문장 구성 능력을 물어요.
- 2027년부터 25문항이 돼요. 영역별 배분은 아직 발표되지 않았으니 시간 배분과 풀이 순서를 미리 정해 두는 게 좋아요.

## 단계별 공부법
| 단계 | 공부법 |
|---|---|
| 기본 | 인사혁신처 예시문제로 유형부터 확인해요. 국어학·논리학 개념은 필요한 만큼만 익히고, 추론·논리 문제를 매일 조금씩 풀어요 |
| 기출 | 2025년 이후 신기조 기출과 예시문제를 반복해요. 2024년 이전 기출의 문법·한자·문학 문항은 효용이 낮은 편이에요 |
| 실전 | 신기조 대비 모의고사로 문제량을 채우고, 시간을 재고 풀어요. 합격자 사례에서는 격일 모의고사에서 시험 한두 달 전 매일 모의고사로 늘렸어요 |
| 마무리 | 틀린 유형과 실수 노트 위주로 봐요. 새 문법 범위는 늘리지 않아요 |

## 고민별 처방
| 고민 | 처방 |
|---|---|
| 추론 문제가 감으로 풀림 | 지문 밖 배경지식은 빼고, 지문 안 근거 문장에 표시한 뒤 선지와 맞춰 봐요 |
| 강화·약화 문제를 자주 틀림 | **지문의 주장을 먼저 한 줄로 요약**하고, 선지가 그 주장을 지지하는지 반박하는지 판단해요 |
| 명제논리가 헷갈림 | 기호로 바꾸고 대우·삼단논법 같은 기본 규칙으로 풀어요. 감으로 풀지 않아요 |
| 독해 시간이 부족함 | 주장과 대립·동의 지점을 표시하며 요약하듯 읽고, 지문당 목표 시간을 정해요 |
| 실수로 틀림 | 부정형 발문에 표시하고 선지를 끝까지 읽어요. 어려운 문항은 표시하고 넘겨요 |
| 문법·한자 암기에 시간을 많이 씀 | 우선순위를 낮춰요. 확인·응용추론 → 논리비판 → 의사소통·공문서 → 지문형 국어학 순서가 안전해요 |
