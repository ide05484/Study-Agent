# 보건직 합격 코치 디자인 시스템

보건직 공무원 수험생이 한 손으로 쓰는 공부 코치 앱(PWA)의 화면 규칙이다. 채팅이 중심이고, 화면은 수험생의 플래너처럼 보인다. 웜그레이 모노톤 위에 주황을 **형광펜 자국**으로만 쓴다.

## 원칙

- **채팅이 중심.** 앱을 열면 오늘의 채팅방이 보인다. 대시보드(현재 공부상태)와 공부 설정은 사이드바에서 들어간다. 하단 탭은 없다.
- **모바일 우선.** 콘텐츠 최대 폭은 `content-max`(480px). 화면 좌우 여백은 `space-4`.
- **플래너처럼.** 영역은 카드가 아니라 `border` 괘선으로 나눈다. 그림자·그라데이션·장식 라벨은 쓰지 않는다(예외: `shadow-popover`, 떠 있는 달력 창 하나).
- **형광펜 하나로 충분하다.** 눈에 띄어야 할 것은 `marker` 하나로 표시한다. 한 화면에 여러 군데 긋지 않는다.
- **응원하는 톤.** 짧고 따뜻한 해요체.

## 문구

- 해요체 존댓말. "~해요", "~해볼까요?" 반말·합쇼체는 쓰지 않는다.
- 코치는 옆에서 기록을 같이 보는 다정한 선배처럼 말한다. 평가·훈계하지 않는다.
- 칭찬과 지적은 기록의 숫자에 근거한다. "지난 모의고사보다 영어가 8점 올랐어요."
- 이모지는 메시지당 0~1개, 의미가 있을 때만(연속 공부 🔥).
- 오류 문구는 탓하지 않고 다음 행동을 알려 준다. "목록을 불러오지 못했어요. 잠시 후 다시 열어주세요."
- 실제 문구 예
  - 첫 메시지: "오늘 하루도 화이팅! 합격까지 달려봐요"
  - 빈 상태: "오늘 배정된 분량이 없어요." + "교재 추가하기"
  - 지난 채팅방: "지난 대화는 볼 수만 있어요."
  - 로그인 실패: "로그인하지 못했어요. 다시 시도해 주세요."
- 숫자 표기: 쪽수는 `12–14쪽`(엔 대시), 진도는 `120/300쪽`, D-day는 `D-123`·`D-DAY`·`D-?`.

## 색상

- 배경은 `bg`, 한 단계 들어간 면(코치 말풍선, 사이드바)은 `surface`. 본문 글자는 `text`, 보조 글자는 `text-muted`.
- 주황 `accent`는 포인트로만 쓴다: 주요 버튼 바탕(글자는 `on-accent`), D-day, 진도율 막대, 활성 메뉴 글자, 고른 날짜. 넓은 면은 웜그레이로 채운다.
- `accent-soft`는 내 말풍선과 활성 메뉴 배경이다. 위 글자는 `text`.
- `marker`는 글자 아래쪽 절반에만 칠한다(`linear-gradient(transparent 55%, var(--marker) 55%)`). 오늘 할 분량, 남은 분량 쪽수에 쓴다.
- `danger`는 오류 문구 글자색으로만 쓴다.
- 과목은 색이 아니라 라벨(국어·영어·공중보건·보건행정)로 구분한다. 진도율 막대는 모두 `accent`.
- 공부 잔디는 `heat-0`~`heat-4` 다섯 단계. 단계를 색만으로 알리지 않도록 칸마다 날짜와 단계 이름을 title로 단다.
- `kakao`·`on-kakao`는 카카오 로그인 버튼에만 쓴다.
- 대비 메모: 라이트의 `accent` 글자(4.36:1)와 `surface` 위 `text-muted`(4.2:1)는 작은 글자 기준 4.5:1에 조금 못 미친다. 값은 코드 그대로 두었다.

## 타이포그래피

- 글꼴은 Noto Sans KR 한 가족(`--font-sans`). 줄 간격 1.5.
- 크기: `caption` 12 / `small` 14 / `section-title` 15 / `body` 16 / `header-title` 17 / `login-title` 26 / `streak-number` 34px.
- 굵기는 400(본문), 600(과목 이름·버튼), 700(제목·D-day·숫자 강조) 세 가지.
- D-day, 진도율, 쪽수처럼 줄 맞춰 읽는 숫자는 `font-variant-numeric: tabular-nums`.
- 제목의 한 단어만 색·굵기를 바꾸는 강조, 영어 대문자 라벨, 가운뎃점(` · `)으로 이어 붙인 나열은 쓰지 않는다.

## 간격·크기·모서리

- 간격은 `space-1`~`space-6`(4·8·12·16·20·24px). 영역 위아래는 `space-5`, 화면 좌우는 `space-4`.
- 누르는 것은 모두 `touch-target`(44px) 이상: 햄버거, 아코디언 행, 삭제 버튼, 메뉴 행.
- 헤더는 `header-height`(56px), 세 칸 그리드(햄버거 / 제목 / D-day).
- 모서리: 버튼·입력 칸 `radius-xl`, 말풍선 `radius-2xl`(꼬리 쪽만 `radius-sm`), 채팅 입력·보내기·날짜 칸 `radius-full`, 메뉴 행 `radius-nav`, 잔디 칸 `radius-xs`.

## 레이아웃

- 공통: 헤더 + 본문. 사이드바는 햄버거로 왼쪽에서 밀려 나오고(폭 80%, 최대 `sidebar-max`), 바깥은 `scrim`으로 덮는다.
- 채팅: 맨 위에 오늘의 분량 한 줄(44px, 접힘), 가운데 말풍선 목록, 아래 입력 줄 고정.
- 대시보드: 공부 잔디 → 연속 공부 → 이번주 목표량 → 과목별 진도율, 영역마다 괘선.
- 공부 설정: 시험일 → D-Day까지 남은 공부 분량 → 과목별 공부법, 영역마다 괘선.
- 아코디언으로 펼친 하위 목록은 왼쪽 2px `border` 괘선으로 들여 쓴다.

## 아이콘

- 아이콘 세트는 없다. 필요한 몇 개(햄버거, 보내기 화살표, 펼침 꺾쇠, 달력, 이전·다음)를 24px 그리드의 선 아이콘(선 굵기 1.8~2.2, 둥근 끝)으로 인라인 SVG에 그리고 `currentColor`를 쓴다.
- 펼침 꺾쇠는 테두리 두 변을 45° 돌린 8px 사각형이다. 열리면 위를 향하게 돌린다.
- 삭제는 `✕` 글자를 `text-muted`로 쓴다. 이모지를 아이콘 대신 쓰지 않는다.
- 로고는 아직 없다. 앱 이름은 글자로만 쓴다.

## 코치 캐릭터: 합격이

- 웜그레이 얼룩무늬에 주황 필승 머리띠를 두른 햄스터. 수험생 옆에서 같이 공부하는 동지다.
- 그림은 `Frontend/src/assets/mascot/`의 SVG 네 장이다(120×120, 표정마다 한 장). 새로 그리지 말고 이 파일을 쓴다.

| 파일 | 표정 | 쓰는 곳 |
|---|---|---|
| `hapgyeok-cheer.svg` | 응원(만세, 반짝이) | 로그인 화면 제목 위 |
| `hapgyeok-think.svg` | 생각 중(눈 감고 점 세 개) | 앱 시작·로딩 화면 가운데 |
| `hapgyeok-oops.svg` | 당황(점눈, 땀방울) | 404·오류 화면 |
| `hapgyeok-base.svg` | 기본 | 빈 상태 등 그 밖의 안내 화면 |

- **내용이 적은 화면에만** 쓴다: 로그인, 앱 시작(로딩), 404. 채팅·대시보드·공부 설정처럼 정보가 많은 화면에는 넣지 않는다. 눈에 띄는 요소는 형광펜 하나로 충분하다는 원칙을 지키기 위해서다.
- 한 화면에 한 마리, 한 표정만 쓴다. 크기는 로그인 140px, 시작 화면 160px, 404 150px.
- 색은 테마와 상관없이 고정이다. 다크 모드에서도 같은 그림을 쓴다(몸이 밝아 어두운 바탕에서도 보인다).
- 선은 1.8px 연한 웜브라운(`#7a6a60`), 눈은 흰자 없는 점눈. 머리띠는 `accent`(라이트 값 `#c4530f`)이고, 머리 곡선을 따라 휘어 몸 윤곽에 맞춰 잘린다.
- 이름은 코치를 부를 때만 쓴다. 예: "코치 합격이가 오늘 공부할 분량을 정해 드려요." 채팅 말풍선 옆에 아바타로 붙이지 않는다.
- 그림 옆에는 장식이 아니라 그 화면의 할 일을 적는다. 예: 404는 "길을 잃었어요" + "오늘 채팅으로 가기" 버튼.

## 상태와 움직임

- 비활성: 버튼 `opacity: .5`(보내기 버튼은 `.4`), 입력 칸 `.6`.
- 포커스: 2px `accent` 윤곽선, 2px 띄움.
- 움직임은 사용자 동작에 반응하는 전환만(사이드바 200ms, 꺾쇠 회전). 화면 진입 애니메이션은 없다. `prefers-reduced-motion`이면 전환을 끈다.
- 로딩은 "불러오는 중…" 글자, 빈 상태와 오류는 각각 문구로 보인다.

## 구현과 연결

- 코드에서는 Tailwind v4 색상 이름을 쓴다: `bg`→`bg-bg`, `text`→`text-fg`, `text-muted`→`text-muted`, `border`→`border-line`. 토큰 값은 `Frontend/src/index.css`의 CSS 변수와 같다.
- 컴포넌트 미리보기는 지금 코드(`Frontend/src/components/`)를 보고 손으로 다시 그린 정적 화면이다. 코드에는 아직 `Button` 같은 공용 컴포넌트가 없고 `components/ui/classes.ts`의 클래스 묶음을 쓴다.
